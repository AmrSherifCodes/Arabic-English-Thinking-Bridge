# Contributing to Thinking Bridge

We welcome contributions from language learners, developers, and linguists worldwide!

## How to Contribute
1. Fork the repository and create a feature branch (`git checkout -b feat/my-feature`).
2. Run `npm install` and verify `npm test` and `npm run build` pass cleanly.
3. Keep changes typed and test-covered.
4. Open a Pull Request with a clear summary of your changes.

## Code of Conduct
Please adhere to our [Code of Conduct](./CODE_OF_CONDUCT.md) in all interactions.
